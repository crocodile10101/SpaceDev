Политика конфиденциальности

Настоящая Политика конфиденциальности персональных данных действует в отношении всей информации, которую сайт SpaceDev (далее — Сайт) может получить о Пользователе во время использования Сайта.

1. Общие положения

1.1. Использование Сайта означает согласие Пользователя с настоящей Политикой и условиями обработки персональных данных.

1.2. В случае несогласия с условиями Политики Пользователь должен прекратить использование Сайта.

2. Какие данные собираются

2.1. Сайт не собирает персональные данные автоматически (без действия Пользователя).

2.2. Пользователь может добровольно передать свои данные (имя, номер телефона, ссылку на профиль в мессенджере) при переходе по ссылкам на мессенджеры (Telegram, WhatsApp, Макс) для обсуждения заказа.

2.3. Сайт может использовать файлы cookie для корректной работы и анализа посещаемости (если подключены сервисы статистики).

3. Цели обработки данных

3.1. Данные используются исключительно для связи с Пользователем по вопросам, связанным с разработкой сайтов, и для ответа на запросы.

3.2. Данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.
